# IT Architecture Books

A three-book self-study course on IT architecture, from software and solution architecture through
design evaluation to enterprise architecture.

| Book | Focus | Pages | Chapters | Exercises | Figures | References |
|---|---|---|---|---|---|---|
| 1. IT Architecture Course Book | Foundations, reasoning and worked architectures, with 12 labs | 186 | 25 | 137 | 37 | 99 |
| 2. IT Architecture in Practice | Design evaluation and decision-making through case studios | 97 | 16 | 86 | 20 | 42 |
| 3. Enterprise Architecture | Strategy, governance and transformation | 109 | 17 | 97 | 18 | 70 |

Every exercise has a worked answer, each book has a glossary and an index, and all code is printed in the
books (Python 3.10+, standard library; SQL for PostgreSQL in Book 2).

## Contents

- `IT_Architecture_Series/books/` — PDF and editable Word files (revised edition, October 2026)
- `IT_Architecture_Series/practice/` — optional copies of the printed listings and templates
- `IT_Architecture_Series/authoring/` — Markdown manuscripts, references, figure sources and build scripts
- `IT_Architecture_Series/archive/` — the previous edition (4 October 2026) and its records
- `IT_Architecture_Series_Revised_2026-10.zip` — the whole revised edition in one archive (without `archive/`)
