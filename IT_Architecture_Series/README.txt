books/ contains the three PDFs (the checked layout) and their editable Word files.

  Book 1  IT Architecture Course Book — Foundations, reasoning and worked architectures
          186 pages, 25 chapters, 12 labs, 137 exercises with answers, 37 figures, 99 references, glossary, index
  Book 2  IT Architecture in Practice — Design evaluation and decision-making
          97 pages, 16 chapters, 86 exercises with answers, 20 figures, 42 references, glossary, index
  Book 3  Enterprise Architecture — Strategy, governance and transformation
          109 pages, 17 chapters, 97 exercises with answers, 18 figures, 70 references, glossary, index

Each book is a self-contained textbook. Every lab, listing, dataset and template a reader needs is printed in
the book. The organisations, workloads, budgets and datasets are fictional teaching examples.

practice/ holds optional exact copies of the printed Python listings and templates, to save retyping.
Python 3.10 or newer, standard library only.

authoring/ holds the Markdown manuscripts, reference lists, figure sources and the build scripts that produce
the Word and PDF files. See authoring/README.txt and authoring/STYLE_GUIDE.md.

Design_Identity.txt describes the visual system. Review_Record.txt records how this edition was checked and
what has not been checked. archive/ keeps the previous edition and its records unchanged.
