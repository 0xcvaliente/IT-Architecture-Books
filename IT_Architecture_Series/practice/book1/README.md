# Book 1 lab listings

These files are optional copies of the Python listings printed in the "Practical labs"
chapter of the IT Architecture Course Book. The book contains everything each lab needs;
the files only save retyping.

Each file holds a lab's listings in the order printed. Run it with Python 3.10 or newer,
for example `python3 lab2_domain.py`. The programs use the standard library only and
never contact external services. Their output matches the expected output shown in the book.

Labs 1, 6 and 12 are design exercises without code; their tables are printed in the book.

`ch12_history_checker.py` is the linearizability checker printed in Chapter 12.
