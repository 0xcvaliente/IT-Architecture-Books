Book 2 support materials: IT Architecture in Practice

Python 3.10 or newer, standard library only. No network access or cloud account needed.
Run each program with: python3 <filename>

Each program reproduces a listing printed in the book exactly, with the same output.

  recovery_and_evidence.py    Chapter 2   drain-time model and zero-failure bound
  reservation_schedules.py    Chapter 8   reservation and payment state model
  publication_ledger.py       Chapter 10  publication ledger for late, replayed and corrected data
  migration_reconciliation.py Chapter 13  key-set and value reconciliation in SQLite
  authorisation_matrix.py     Chapter 11  tenant-aware access matrix for analytical data
  dossier_templates.md        Experiments, templates and research tasks chapter

The PostgreSQL listings (Chapters 4, 6, 7 and 13) are printed in the book.
The final chapter of the book suggests an extension for each experiment.
